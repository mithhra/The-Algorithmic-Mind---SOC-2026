# The Algorithmic Mind - SOC'2026

This repository will serve as the central workspace for all learning materials, weekly tasks, problem sets, and solution submissions.

The goal of this project is not just solving problems, but learning how to identify patterns, choose appropriate algorithms and data structures, and build strong problem-solving intuition for competitive programming.

---

#  Repository Structure

Each week contains:

- Learning resources
- Recommended videos
- Practice problems
- Submission tasks
- Additional challenges

Students are expected to:

1. Complete the assigned learning resources.
2. Watch the recommended videos.
3. Solve the submission questions.
4. Upload solutions in the corresponding week's folder(The submitting file's name should be your name).
5. Attempt practice problems whenever possible.

# Week 1 - Complexity Analysis, Prefix Sums & Binary Search

## Objective

This week focuses on building the foundation required for every future topic in DSA. Before solving complex problems, it is important to understand how to analyze algorithms, use C++ STL efficiently, and recognize common problem-solving techniques such as prefix sums and binary search.

By the end of this week, you should be comfortable with:

- Time and Space Complexity analysis
- Using commonly used STL containers and functions
- Prefix Sum technique
- Standard Binary Search
- Binary Search on Answers
- Solving beginner-level CSES problems independently

# Notes

- Focus on understanding patterns rather than memorizing solutions.
- If stuck for more than 30–45 minutes, revisit the concept and attempt again.
- Maintain notes containing:
  - Key idea
  - When to use the technique
  - One representative example problem
